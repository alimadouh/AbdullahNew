## 3. Problems found but not fixed

1. **Diltiazem QT change affects other files (integrator).** Rules in other batches written as `other: group:qt-prolonging` will no longer fire for diltiazem. Diltiazem's own caution rule still flags every QT pair. If the integrator wants diltiazem kept in the group, it needs a UK source that says it prolongs QT at therapeutic doses; none was found.
2. **Atenolol wording coded differently in batch M.** `atenolol-bendroflumethiazide` codes the same "can lead to an exaggeration of these effects" text as caution for verapamil/diltiazem; here it is info (no action stated). One of the two should be aligned by the integrator.
3. **Nifedipine product match stays uncertain.** The clinic lists a 30 mg "retard" tablet. No UK 30 mg twice-daily retard tablet exists. The once-daily SmPC is kept (same strength) with a clear note and a detail item from a UK 20 mg twice-daily retard SmPC. The clinic should confirm which release type it stocks.
4. **Nifedipine macrolide rule includes azithromycin.** The SmPC lists "macrolide antibiotics (e.g., erythromycin)" as a class among CYP3A4 inhibitors, so `group:macrolide` is faithful to the text, but azithromycin is not a CYP3A4 inhibitor. Left as written (monitor level).
5. **Atenolol renal unit.** The SmPC gives creatinine clearance in "ml/min/1.73 m2"; the engine treats CrCl as mL/min. Concern text keeps the SmPC unit.
6. **Suggested `conditionImplies` (tool.json, not edited):** `hocm` → `aortic-stenosis` (vocab name "Aortic stenosis / LV outflow obstruction"), plus the batch N suggestions already in `sources/N.json` notes.
7. **Verapamil 80 mg tablet SPC text.** Its 4.1 refers to "section 4.3 for warning regarding concomitant administration with beta-blockers", but 4.3 has no such warning. Nothing to code.
8. **GTN 4.8 table** is garbled in both PDF texts; common effects are listed without frequencies (unchanged).
