# Audit: batches R and S

Batch R: diclofenac, etoricoxib, celecoxib, mefenamic acid, aspirin, paracetamol/chlorzoxazone, orphenadrine/paracetamol.
Batch S: cetirizine, levocetirizine, loratadine, desloratadine, loratadine/pseudoephedrine, cetirizine/pseudoephedrine.

Independent second check, 2026-10-17. Every source in `sources/R.json` and `sources/S.json` was re-read in full (sections 4.1 to 4.6, plus 4.8 and 5.1 where a rule depends on them) from the shared cache. The clinic product list (`clinic-map.json`) was compared with each UK product. emc and the MHRA Products index were searched again for the four combination products. After the edits: schema check 0 errors and 0 warnings; all 1,513 quotes in the 11 medicine files with content are FOUND (same normaliser as `verify.mjs`). An in-memory engine run confirmed the new rules fire as intended (for example diclofenac gastro-resistant + low-dose aspirin = avoid; analgesic aspirin + warfarin = contraindicated; celecoxib + nebulised budesonide = no finding, celecoxib + prednisolone = caution).

## 2. Coordinator points checked

- **Diclofenac systemic rules scoped to oral/rectal.** Confirmed; every systemic rule now lists the four oral/rectal formulations, never the gels. Gel rules are only the ones the gel SmPCs list (hypersensitivity, NSAID asthma, third trimester, T1-T2, asthma caution, gel-specific items).
- **Aspirin 100 mg not a UK strength.** Confirmed (emc and MHRA list 75 mg and 300 mg). Separate low-dose and analgesic formulations now exist (#7 to #9).
- **Coxibs contraindicate ACTIVE ulcer only.** Confirmed for etoricoxib and celecoxib. Both `gi-ulcer-bleed` concerns start with "Active peptic ulceration…" and the action says a past history needs caution only (4.4).
- **NSAID group membership.** Complete and sourced: diclofenac, etoricoxib, celecoxib, mefenamic acid (plus ibuprofen, naproxen from batch A). Aspirin is not in `nsaid`. Where an SmPC names aspirin, an aspirin rule exists: allergy rules of diclofenac, etoricoxib, celecoxib, mefenamic acid list `aspirin`; interaction rules diclofenac (caution, plus avoid for the gastro-resistant SmPC), etoricoxib (low dose caution, analgesic dose avoid), celecoxib (caution), mefenamic acid (avoid). Aspirin's own rules cover `group:nsaid` (allergy contraindicated, interaction avoid).
- **Pseudoephedrine combinations no-uk-product.** Confirmed again: emc search returns nothing for either pair or the trade names; MHRA Products has no SPC with either pair. Group `sympathomimetic` membership is sourced (MHRA DSU 2024: pseudoephedrine is a sympathomimetic approved in fixed combinations with antihistamines). No other memberships added (none sourced).

## 3. Problems found but not fixed (other files or integrator)

- **fluconazole.json** `fluconazole:interaction:diclofenac` uses the exact id `diclofenac` with no `otherFormulations`, so it fires for the diclofenac gels. Suggest `otherFormulations: ["diclofenac-k-tab","diclofenac-gr-tab","diclofenac-mr-tab","diclofenac-supp"]`.
- **ibuprofen.json, naproxen.json** NSAID-allergy rules use only `group:nsaid`. Their SmPCs name aspirin, and aspirin is not in the group, so an aspirin allergy does not trigger them. Add `"aspirin"` to `allergen`.
- **Dose-dependent aspirin rules in other batches** (candesartan, valsartan, valsartan-hydrochlorothiazide, amlodipine-valsartan, telmisartan, telmisartan-hydrochlorothiazide, perindopril, perindopril-amlodipine, lisinopril-hydrochlorothiazide, indapamide, hydrochlorothiazide, budesonide-nebuliser "analgesic doses", allopurinol "large doses") fire for low-dose aspirin. They can now add `otherFormulations: ["aspirin-analgesic"]`. Rules about low-dose aspirin can use `["aspirin-75-tab","aspirin-75-gr"]`.
- **Group `corticosteroid`** mixes oral prednisolone/dexamethasone with nebulised budesonide and inhaled/nasal beclometasone. Many other batches' "corticosteroid" GI-bleeding or hypokalaemia rules use the group and will fire for inhalers and nebulisers. Consider a separate `systemic-corticosteroid` group.
- **clinic-map.json**: the "Diclofenac sodium / Voltaren / Tablets 50 mg" row should point to formulation `diclofenac-gr-tab` and its SmPC link (PL 00289/0739), not the potassium SmPC (emc 4333).
- **Mefenamic acid generic SmPC** contraindicates "concomitant NSAIDs including COX-2 inhibitors" (4.3) and says "including aspirin" in 4.5. With aspirin outside `nsaid`, aspirin gets the originator "avoid" rule, not the generic "contraindicated" one. Left as is (aspirin avoid rule exists; 4.3 itself does not name aspirin).
- **No-uk-product combinations** (loratadine/pseudoephedrine, cetirizine/pseudoephedrine) keep MHRA DSU and SPS/BUMPS class advice as section items. SCHEMA says every section should be not-available; the batch notes say this was requested. Integrator to confirm.
- **Diclofenac renal and hepatic "failure"** rules map to `severe-renal-impairment` (linked to GFR <30) and `hepatic: severe`. This is the batch-wide convention but is broader than "failure".
- **Desloratadine and QT**: 4.8 lists QT prolongation (post-marketing, frequency not known) and 5.1 found none at 45 mg; SPS list does not name it. Not added to `qt-prolonging`, following the QT policy.
